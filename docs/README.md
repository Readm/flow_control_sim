# FlowSim Documentation

This directory contains the documentation for the FlowSim project.

## Structure

- **[architecture/](architecture/)**: System architecture, core entity definitions, and high-level design documents.
- **[protocols/](protocols/)**: Communication protocol specifications (e.g., CHI, Transaction).
- **[key_features/](key_features/)**: detailed design documents for specific features.
- **[guides/](guides/)**: User guides and development guides.
- **[analysis_reports/](analysis_reports/)**: Performance analysis, test reports, and case studies.
- **[archive/](archive/)**: Archived development logs, old design proposals, and historical records.

## Contributing

When adding new documentation, please categorize it into the appropriate subdirectory.
