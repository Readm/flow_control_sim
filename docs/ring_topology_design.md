# Ring 拓扑设计：32 核系统

## 拓扑结构

```
Ring 结构 (8 个 L3 + 8 个 HA，共 16 个节点在环上)

     HA0 ---- HA1 ---- HA2 ---- HA3
      |        |        |        |
     L3_0    L3_1     L3_2     L3_3
      |        |        |        |
   +--+--+  +--+--+  +--+--+  +--+--+
   |  |  |  |  |  |  |  |  |  |  |  |
  L2 L2 L2 L2 L2 L2 L2 L2 L2 L2 L2 L2 L2 L2 L2 L2
   |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |
  C0 C1 C2 C3 C4 C5 C6 C7 C8 ...            C30 C31

Ring 继续:
     HA7 ---- HA6 ---- HA5 ---- HA4
      |        |        |        |
     L3_7    L3_6     L3_5     L3_4
      |        |        |        |
   DRAM7    DRAM6    DRAM5    DRAM4

注：HA7 连接回 HA0 形成环
```

## 节点 ID 分配

| 节点类型 | ID 范围 | 数量 | 说明 |
|---------|---------|------|------|
| CPU     | 0-31    | 32   | 每个 L2 连接 1 个 CPU |
| L2      | 32-63   | 32   | 每个 L3 连接 4 个 L2 |
| L3      | 64-71   | 8    | 在 Ring 上 |
| HA      | 72-79   | 8    | 在 Ring 上，有 Directory |
| DRAM    | 80-87   | 8    | 每个 HA 连接 1 个 DRAM |

**总节点数**: 80

## 连接关系

### 1. CPU <-> L2 (1:1)
```
CPU[i] <-> L2[32+i]  (i = 0..31)
```

### 2. L2 <-> L3 (4:1)
```
L2[32+i] <-> L3[64 + i/4]  (i = 0..31)

示例：
- L2[32,33,34,35] <-> L3[64]
- L2[36,37,38,39] <-> L3[65]
- ...
- L2[60,61,62,63] <-> L3[71]
```

### 3. L3 <-> HA (1:1 本地连接)
```
L3[64+i] <-> HA[72+i]  (i = 0..7)
```

### 4. HA Ring 连接
```
HA[72+i] <-> HA[72 + (i+1)%8]  (双向，形成环)

具体连接：
HA72 <-> HA73
HA73 <-> HA74
HA74 <-> HA75
HA75 <-> HA76
HA76 <-> HA77
HA77 <-> HA78
HA78 <-> HA79
HA79 <-> HA72  (闭环)
```

### 5. HA <-> DRAM (1:1)
```
HA[72+i] <-> DRAM[80+i]  (i = 0..7)
```

## 一致性树设计

### Directory 配置
- **Directory 位置**: HA (Home Agent)
- **Directory 数量**: 8 个 (HA72-HA79)

### Coherence Domain 划分
```
HA72 Domain: CPU[0,1,2,3], L2[32,33,34,35], L3[64]
HA73 Domain: CPU[4,5,6,7], L2[36,37,38,39], L3[65]
HA74 Domain: CPU[8,9,10,11], L2[40,41,42,43], L3[66]
HA75 Domain: CPU[12,13,14,15], L2[44,45,46,47], L3[67]
HA76 Domain: CPU[16,17,18,19], L2[48,49,50,51], L3[68]
HA77 Domain: CPU[20,21,22,23], L2[52,53,54,55], L3[69]
HA78 Domain: CPU[24,25,26,27], L2[56,57,58,59], L3[70]
HA79 Domain: CPU[28,29,30,31], L2[60,61,62,63], L3[71]
```

### 地址映射
- **粒度**: 64B (cache line)
- **策略**: 8 路交错
- **映射函数**: `HA_ID = 72 + ((addr / 64) % 8)`

### 跨 Domain 路由
- CPU[0] 访问 HA73 管理的地址：
  - 路径: `CPU0 -> L2[32] -> L3[64] -> HA72 -> HA73`
- CPU[0] 访问 HA79 管理的地址：
  - 路径: `CPU0 -> L2[32] -> L3[64] -> HA72 -> HA79` (Ring 上最短路径)

## 性能测试场景

### Benchmark 1: 单核基准
- **配置**: 1 CPU + 1 L2 + 1 L3 + 1 HA + 1 DRAM
- **Workload**: 1M 指令
- **目标**: 测量单核仿真速度

### Benchmark 2: 32 核 Ring
- **配置**: 32 CPU + 32 L2 + 8 L3 + 8 HA + 8 DRAM (Ring)
- **Workload**: 每个核 1M 指令 (共 32M)
- **目标**: 测量多核并行仿真速度

### 对比指标
1. **仿真吞吐量**: KIPS (Kilo Instructions Per Second)
2. **扩展性**: 32 核吞吐量 / 单核吞吐量
3. **内存**: 仿真占用的内存
